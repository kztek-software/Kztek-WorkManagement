# STEP 3.2: Kiểm Thử Toàn Diện & Ký Duyệt Nghiệm Thu (QA Sign-off)

## Mục tiêu
Thực hiện script kiểm thử tự động, kiểm tra hồi quy toàn bộ chức năng trên môi trường di động và ký duyệt hoàn thành Giai đoạn 2 (GD2).

## Danh sách công việc
1. Chạy script kiểm thử `scripts/test-mobile-responsiveness.js`.
2. Kiểm tra các luồng nghiệp vụ trên mobile:
   - Đăng nhập $\rightarrow$ Chuyển dự án $\rightarrow$ Xem Dashboard.
   - Thao tác trên Kanban Board $\rightarrow$ Mở chi tiết task $\rightarrow$ Bình luận @mention $\rightarrow$ Đổi trạng thái.
   - Quản lý Sprint $\rightarrow$ Xem chi tiết sprint $\rightarrow$ Gán task.
   - Tiếp nhận Ticket $\rightarrow$ Phân loại & điều phối $\rightarrow$ Cổng thông tin khách hàng.
   - Quản lý nhân sự $\rightarrow$ Phân quyền vai trò trên Mobile.
   - Cài đặt hệ thống $\rightarrow$ Đổi thông số.
3. Tổng kết chất lượng và ký duyệt Sign-off.
