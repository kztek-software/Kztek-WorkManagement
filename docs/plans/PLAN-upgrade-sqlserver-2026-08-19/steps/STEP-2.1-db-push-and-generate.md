# STEP 2.1: Triển khai Schema lên SQL Server & Generate Client

## Mục tiêu
- Thực hiện `npx prisma db push` lên cơ sở dữ liệu `WorkingManager` trên SQL Server `14.160.26.45:9999`.
- Thực hiện `npx prisma generate` để tạo Prisma Client Typescript mới cho SQL Server.
- Xác nhận các bảng, indexes và foreign keys đã được tạo trọn vẹn trong CSDL `WorkingManager`.
