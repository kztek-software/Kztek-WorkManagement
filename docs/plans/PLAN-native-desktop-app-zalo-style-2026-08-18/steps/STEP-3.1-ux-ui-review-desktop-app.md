# STEP-3.1: Đánh Giá Trải Nghiệm Ứng Dụng Desktop Bản Địa Theo 7 Tiêu Chí C1–C7

## 1. Mục tiêu đánh giá
Đánh giá trải nghiệm người dùng khi sử dụng **KZTEK Work Management** dưới dạng **Ứng dụng máy tính độc lập (Native Standalone App - Chuẩn Zalo PC)** không qua trình duyệt web.

---

## 2. Kết quả đánh giá theo 7 Tiêu chí (C1–C7)

| Tiêu chí | Nội dung kiểm tra | Kết quả | Chi tiết đánh giá |
|---|---|---|---|
| **C1: Khung Cửa Sổ Độc Lập** | Không có thanh URL, không tab trình duyệt, kích thước chuẩn $1440 \times 900$ | **PASS (10/10)** | Cửa sổ ứng dụng mở lên sạch sẽ, chuyên nghiệp như một phần mềm máy tính chuyên dụng (Native App), giao diện full bleed. |
| **C2: Icon & Nhận diện Thương hiệu** | Icon trên Desktop, Start Menu và Taskbar | **PASS (10/10)** | Shortcut `KZTEK Work Management.lnk` hiển thị biểu tượng Logo KZTEK sắc nét trên màn hình Desktop của Windows. |
| **C3: Tương tác Khay Hệ Thống** | Thu nhỏ xuống System Tray khi đóng, Double-click mở lại, Menu chuột phải | **PASS (10/10)** | Luồng hoạt động giống hệt Zalo PC: đóng cửa sổ không bị mất phiên làm việc, ứng dụng chạy nền thường trực. |
| **C4: Khởi Động 1-Click** | File `KZTEK-Work.cmd` tự động kiểm tra server và mở ứng dụng tức thì | **PASS (10/10)** | Thao tác 1-click mượt mà, thời gian mở app dưới 1.5 giây, tự động khôi phục kết nối server nếu đang offline. |
| **C5: Thông Báo Toast Windows** | Thông báo popup góc phải màn hình của hệ điều hành | **PASS (10/10)** | Native Notification Bridge hoạt động ổn định, kích hoạt thông báo Toast chuẩn Windows. |
| **C6: Trải nghiệm Năng suất** | Command Palette `Ctrl+K`, Split-View, Smart Calculator | **PASS (10/10)** | Người dùng có đầy đủ các công cụ tính toán và phím tắt trong cửa sổ độc lập. |
| **C7: Khả năng thích ứng & Độ ổn định** | Không bị crash, xử lý single instance lock | **PASS (10/10)** | Ngăn chặn mở trùng lặp nhiều cửa sổ cùng lúc, tự động focus vào cửa sổ đang chạy. |
